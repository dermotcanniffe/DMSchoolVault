# 🧩 Templates — How to use them

⬅ Back to [[Home]]

These are fill-in-the-blank starting points so you never face a blank page. Anything in `{curly braces}` is a slot for you to fill; delete the braces as you go. Anything after `>` is a hint.

## Two ways to use a template

**A) Quick copy/paste (works right now, no setup)**
1. Open the template you want (list below).
2. Copy the whole thing.
3. Make a new note where you want it and paste. Fill in the blanks.

**B) One-click insert (recommended — 30-second setup)**
Turn on Obsidian's built-in **Templates** plugin so you can drop these in with one command:
1. Settings → **Core plugins** → toggle on **Templates**.
2. Settings → **Templates** → set *Template folder location* to `03 - Templates`.
3. In any note, run the command **"Templates: Insert template"** (Ctrl/Cmd-P to find it) and pick one.

## The templates
- [[03 - Templates/NPC|NPC]] — a person the party can meet
- [[03 - Templates/Location|Location]] — a place they can visit
- [[03 - Templates/Encounter|Encounter]] — a scene, fight, or challenge
- [[03 - Templates/Session Prep|Session Prep]] — plan a game night
- [[03 - Templates/Quest|Quest / Adventure]] — a goal with hooks and stakes
- [[03 - Templates/Setting Seed|Setting Seed]] — turn a one-line idea into a place
- [[03 - Templates/Stat Block Boxout|Stat Block Boxout]] — a collapsible stat block to paste into any note

> [!tip] Filling the blanks
> Don't have an answer for a slot? Leave it or write `TBD`. A half-filled template is still miles ahead of nothing. For any of these you can ask the AI helper to fill them in — see [[02 - Reference/Using AI Helpers|Using AI Helpers]].
