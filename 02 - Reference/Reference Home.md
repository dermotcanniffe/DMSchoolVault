# 📚 Reference — rules & the math, made easy

⬅ Back to [[Home]]

These sheets are built so you **look up an answer instead of calculating it**. No mental arithmetic required — find the row, read the number.

> [!info] System note
> The numbers here follow **D&D 5th Edition** (the most common system). The *ideas* (roll a die, add a number, compare to a target) are the same in most RPGs, so these still help even at a different table.

> [!tip] The golden rule for the math
> If a number ever feels stressful: **you are allowed to guess a round number and move on.** Nobody at the table can tell the difference between a "correct" DC 15 and a "vibes" DC 15. These sheets remove the guesswork, but the game survives approximation just fine.
