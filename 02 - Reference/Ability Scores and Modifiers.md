# 💪 Ability Scores & Modifiers

⬅ [[02 - Reference/Reference Home|Reference Home]]

Every creature has six ability **scores** (usually 1–20+). Each score has a **modifier** — the actual bonus you add to rolls. **You never have to work out the modifier. Just look it up here.**

## The lookup table (this replaces the formula)

| Score | Modifier (the bonus you add) |
|------:|:----------------------------|
| 1     | −5 |
| 2–3   | −4 |
| 4–5   | −3 |
| 6–7   | −2 |
| 8–9   | −1 |
| 10–11 | **0** (no bonus) |
| 12–13 | +1 |
| 14–15 | +2 |
| 16–17 | +3 |
| 18–19 | +4 |
| 20–21 | +5 |
| 22–23 | +6 |
| 24–25 | +7 |
| 26–27 | +8 |
| 28–29 | +9 |
| 30    | +10 |

**How to read it:** find the score in the left column, the number on the right is what you add. A score of 16 → you add +3. That's the whole job.

> [!note] The pattern, if it helps (ignore if it doesn't)
> 10 = no bonus. Every 2 points above 10 adds +1; every 2 below subtracts 1. But you never need to do that math — the table already did it.

## What the six abilities mean
| Ability | Short for | It covers |
|---------|-----------|-----------|
| STR | Strength | muscle, lifting, melee swings |
| DEX | Dexterity | agility, aim, stealth, reflexes |
| CON | Constitution | health, stamina, toughness |
| INT | Intelligence | knowledge, logic, memory |
| WIS | Wisdom | awareness, intuition, willpower |
| CHA | Charisma | force of personality, social skill |

## Proficiency bonus (the other number you add)
Trained characters add a **proficiency bonus** on top of the ability modifier for things they're good at. It's set by level — just read it off:

| Character level | Proficiency bonus |
|-----------------|-------------------|
| 1–4   | +2 |
| 5–8   | +3 |
| 9–12  | +4 |
| 13–16 | +5 |
| 17–20 | +6 |

So a skilled roll is often: **d20 + ability modifier + proficiency bonus.** All three numbers are written on the sheet — reading, not calculating. If totalling three numbers is a lot, let the player add their own; that's how most tables run anyway.
